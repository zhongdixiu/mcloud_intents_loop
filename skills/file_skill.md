# 文件管理工具 Skill

## Skill Scope

本 Skill 负责：

- 文件分类浏览；
- 最近查看和收听；
- 文件上传；
- 回收站；
- 收藏和私密存储；

本 Skill 不负责：

- 按内容搜索云盘资源；
- AI 图片生成与编辑；
- 文件知识问答；

## Intent Routing Principles

1. 根据用户当前主动作选择 Intent，参数缺失不影响 Route 判断。
2. 专用 Intent 优先于通用入口；同 code 的不同 Intent 仍按完整 Route Key 区分。
3. 当前 Skill 不支持请求时允许返回空候选，不强制选择相近 Intent。
4. 二级阶段保留现有参数输出兼容，但不得因参数不全降低正确 Route 的优先级。

现有业务规则：

1. 能力边界：
    - 本技能仅用于“浏览/管理/上传/清理/安全存储”相关能力，不提供搜索能力。
    - 用户出现“搜索/查找/搜一下/帮我找”等检索意图时，不应命中本技能。
2. 入口选择规则：
    - 出现“最近看过/刚看过/最近追的剧/最近看的电影”等观看历史表达，优先映射“最近在看”。
    - 出现“最近听过/刚听的歌/最近循环的音乐/最近听的故事”等收听历史表达，优先映射“最近在听”。
    - 出现“删除的文件/误删恢复/垃圾箱/回收箱”等恢复诉求，映射“回收站”。
    - 出现“私密/隐私/加密/上锁文件”等安全诉求，映射“保险箱”。
    - 出现“身份证/银行卡/证件/卡片管理”等卡证诉求，映射“我的卡包”。
3. 动作优先级：
    - 同时出现“拍照”和“上传”时，优先“拍照上传”；仅出现“上传文件/导入文件”时使用“文件上传”。
    - 同时出现“相似图/模糊图/低质量图片/重复照片清理”时，优先“图片清理”，不要映射到“图片”浏览。

### 易错用例
| 用户query | 正确工具 | 判定要点 |
|---|---|---|
| 我的音乐 | 音频 | 明确浏览音频文件，映射“音频”入口 |
| 转存资源 | 文件 | “转存/资源”偏文件管理与浏览入口，按文件入口承接 |
| 浏览资源 | 文件 | “浏览资源”是泛浏览诉求，映射“文件”入口 |
| 上传图片 | 文件上传 | 明确上传已有图片；未出现“拍照”不走拍照上传 |
| 上传视频 | 文件上传 | 明确上传已有视频；未出现“拍照”不走拍照上传 |
| 上传手机图片 | 文件上传 | 来源是手机相册中的已有图片，归文件上传 |
| 上传手机照片 | 文件上传 | 来源是手机相册中的已有照片，归文件上传 |

## Intent Contrast Rules

### 文件上传 vs 拍照上传

- 上传手机或本地已存在文件时选择“文件上传”。
- 明确现场拍照并上传时选择“拍照上传”。

### 图片 vs 图片清理

- 浏览已有图片选择“图片”；清理重复、模糊、相似或低质量图片选择“图片清理”。

### 文件管理 vs 云盘搜索（跨 Skill）

- 浏览、管理和上传由本 Skill 承接；按关键词查找内容应交给云盘搜索。

## Intent-Specific Rules

- 每个 Intent 的适用范围以 Tools Schema 的 `desc` 和上述对比规则为准。
- 只抽取用户当前输入或上下文中明确存在的参数，不猜测实体或真实资源句柄。
- 参数缺失不改变已经确定的 Intent；同 code Intent 必须根据名称语义区分。

## Positive Examples

- “把手机里的照片上传云盘” → 文件上传
- “打开回收站” → 回收站

## Negative Examples

- “找昨天的合同” → 云盘搜索
- “生成一张头像” → 图像与视觉工具

## Execution Instructions

- 最终 Route 确定后，按照该 Intent 的参数 Schema 做类型、数组元素和枚举校验。
- 未明确提供的可选参数不阻塞路由；不得伪造文件、图片、邮件等业务句柄。
- 涉及删除、覆盖、外发或权限变更时，由执行阶段完成对象确认和风险确认。
